❓ Frequently Asked Questions

How does SmartHire calculate the ATS Compatibility score?

SmartHire parses your document text using Apache Tika and PDFBox, extracts technical keywords, and validates formatting against standard Applicant Tracking System (ATS) parsing rules. Scores consider skill presence, keyword density, section headers, and experience relevancy.

Which file formats and sizes are supported?

We support standard PDF (.pdf) and Microsoft Word (.doc, .docx) files up to 5 MB. Documents should contain selectable text rather than scanned raster images.

How do I improve my resume's keyword match?

Visit the Skills Gap page to review missing high-priority skills. Incorporate those technologies naturally into your work accomplishments and project descriptions using measurable metrics.

How does the HR Recruiter workflow work?

Recruiters can create job vacancies with specific required and preferred skills, bulk upload resumes, and let the AI compute match scores and side-by-side candidate comparisons to shortlist top talent.
